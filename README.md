# esp32-labs 

Tiny experiments with the ESP32 -- from sinewave buzzers to OLED graphs, Wi-fi tricks and random micropython chaos.

### what's inside
- live serial linked PC RAM visualiser on a 128x32 OLED 
- PWM-based buzzer sounds (to drive a random buzzer i found lying around)
- basic wifi AP demo

### hardware
- ESP32 Devkit WROOM-32 C Type with CP2102 (38 Pins)
- 38-Pin ESP32S Expansion Board
- SSD1306 OLED 128x32
- random piezo / magnetic speaker

Everything here runs on MicroPython
